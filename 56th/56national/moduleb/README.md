# 模組 B － 前端．相片幻燈片（Photo Slideshow）

第 56 屆全國技能競賽　17 網頁技術

## 執行方式

純靜態網頁，不需要任何後端或套件安裝。

- 進入點：<http://127.0.0.1:83/56th/56national/moduleb/>
- 題目要求的 `/module_b/` 路徑：<http://127.0.0.1:83/56th/56national/module_b/>
  （該資料夾內只有一個轉址頁，會 `location.replace()` 到 `../moduleb/`）
- 評測瀏覽器：Google Chrome

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 版面骨架（檢視區、設定視窗、指令列） |
| `index.css` | 共用版面、元件、深色模式、全螢幕樣式 |
| `theme-a.css` | 主題 A：無特效 |
| `theme-b.css` | 主題 B：左進右出 |
| `theme-c.css` | 主題 C：下進上出、字幕逐字 |
| `theme-d.css` | 主題 D：自訂「開窗」轉場 |
| `index.js` | 全部互動邏輯 |
| `material/Sample Photos/` | 題目提供的四張範例相片 |
| `material/icons/` | 題目提供的 SVG 圖示 |

各主題的 CSS 分別存放於獨立檔案，符合「關注點分離」的要求；`index.css` 只負責與主題無關的版面。

## 功能對照

### 載入相片
- **拖曳**：把圖片檔拖進中央檢視區即可載入。
- **上傳**：`Upload Photos` 按鈕開啟檔案選擇器（可多選）。
- **範例相片**：`Load Samples` 按鈕載入 `material/Sample Photos/` 內的四張相片。
- **重複偵測**：以「檔名（不分大小寫）」與「檔名 + 檔案大小」兩把鑰匙比對，重複的檔案會被略過。
- **字幕自動產生**：去掉副檔名 → 連字符／底線換成空格 → 每個單字首字母大寫。
  - `hello.jpg` → `Hello`
  - `hello world.jpg` → `Hello World`
  - `a-sample-photo.jpg` → `A Sample Photo`
- **字幕自訂**：設定視窗的 `Photo Order` 清單中，每一列都有可直接編輯的字幕欄位。

### 播放模式
| 模式 | 行為 |
| --- | --- |
| Manual | 用 `←` `→` 方向鍵或工具列上的 `<` `>` 手動切換 |
| Auto | 依序循環播放，播到最後一張回到第一張 |
| Random | 每次隨機挑選下一張，無限播放 |

- 停留時間 1–30 秒，數字輸入欄與滑桿雙向同步。
- 轉場速度 0.2–5 秒，同樣提供輸入欄與滑桿。
- 自動／隨機模式下，工具列中央的播放／暫停按鈕可暫停與恢復。
- 工具列的 `F` 按鈕對根元素要求全螢幕，瀏覽器工具列與系統工作列都會隱藏。

### 設定視窗
點擊左上角齒輪按鈕開啟（再按一次或按 `ESC`、點背景遮罩可關閉）。內含：
1. 操作模式切換（Manual / Auto / Random）
2. 主題切換（A / B / C / D）
3. 相片排序：清單可用滑鼠拖曳調整順序，另有 `Shuffle Photos` 一鍵隨機打亂
4. 播放設定：停留秒數、轉場速度
5. 顯示設定：深色模式切換

### 主題
以「兩層投影片」實作進場與離場：`#slideOutgoing` 播放上一張的離場動畫，`#slide` 播放新一張的進場動畫。

- **主題 A**：直接顯示，無任何特效（離場層在主題 A 下不顯示）。
- **主題 B**：相片由左側移入中央，再由中央移出右側；字幕採相同的左至右動畫，但延遲 300ms。
- **主題 C**：相片由下方移入中央，再由中央移出上方；字幕逐字向上顯示，每字間隔 300ms。
- **主題 D**（自行設計）：相片以 `clip-path` 由中央「開窗」展開進場，離場時向內收攏並輕微旋轉淡出。

四個主題都吃同一組 CSS 變數，因此深色模式在每個主題下都能正確套用並保持視覺一致。

### 指令列（Command Palette）
- `CTRL + K` 或 `/` 開啟，`ESC` 關閉。
- 開啟時頁面其餘區域會被半透明遮罩變暗。
- 輸入文字會即時做部分比對過濾。
- `↑` `↓` 選取選項（選中項以高亮底色標示），滑鼠移入也會同步選取，`ENTER` 執行。
- 內建指令：
  - Switch to manual mode / autoplay mode / random mode
  - Switch to theme A / B / C / D
  - Toggle dark and light mode
  - Shuffle photos
  - Pause playback / Start playback

### 設定持續性
主題、播放模式、播放間隔、轉場速度、深色模式、播放中狀態都以 `localStorage`（鍵名 `moduleBSettings`）儲存，重新開啟頁面自動還原。

## 已知限制
- 相片本身（Blob URL）不會存進 `localStorage`，重新整理後需重新載入相片；題目只要求保存「使用者偏好設定」。
- 全螢幕需由使用者手勢觸發，這是瀏覽器的安全限制。
