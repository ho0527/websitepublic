B13 - Accessibility（無障礙修正）

主辦單位提供的 accessibility.html 內含五個常見的無障礙問題， 以下列出找到的問題與對應的修正方式，修正後的版本為 accessibility-fixed.html。

開啟修正後版本 accessibility-fixed.html 開啟原始版本 accessibility.html
問題與修正對照表
問題 修正方式
1. 缺少文件宣告、語言與頁面標題 原檔沒有 <!DOCTYPE html>、lang 屬性、 <meta charset> 與 <title>， 螢幕閱讀器無法判斷朗讀語言、分頁也沒有可辨識的名稱。
→ 補上 <!DOCTYPE html>、<html lang="en">、 charset、viewport 與具描述性的 <title>。
2. 用 div 假裝標題 div.header1 / .header2 / .header3 只有字體大小的差異、沒有語意， 輔助科技無法建立標題大綱，使用者也無法用標題快速跳讀。
→ 改為真正的 <h1>、<h2>、<h3>， 並用 CSS 維持原本的視覺大小。
3. 圖片沒有替代文字 <img src="images/web-tech.jpeg"> 缺少 alt， 視障使用者完全得不到圖片資訊。
→ 補上具描述性的 alt 說明圖片內容。
4. 表單欄位沒有 label 搜尋欄位只靠旁邊的文字「Search」表示用途，輸入框本身沒有可及名稱； 送出鈕也只顯示瀏覽器預設文字。
→ 加上 <label for="site-search"> 與對應的 id、name，送出鈕 value 改為「Search」， 表單並加上 role="search" 地標。
5. 文字對比度不足 原本背景 #444444 搭配文字 #888888， 對比度僅約 1.9:1，遠低於 WCAG 2.1 AA 對一般文字要求的 4.5:1。
→ 改為背景 #1f2933 + 文字 #f0f4f8（約 14:1）， 連結色改為 #7fd0ff（約 9:1），並保留底線與可見的鍵盤焦點框。
6. 連結文字「click here」沒有意義 以連結清單方式瀏覽時，「click here」完全無法判斷目的地。
→ 改為描述性文字「WorldSkills Web Technologies skill page」， 並註明會在新分頁開啟。

補充：原始檔案透過 CDN 載入 Bootstrap，在離線環境無法取得而導致版面錯亂， 修正版已移除該 CDN 連結，改以自行撰寫的少量 CSS 呈現相同版面，不依賴任何外部資源。
