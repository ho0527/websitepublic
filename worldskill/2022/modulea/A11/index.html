A11: Banner creation

用提供的素材製作 300×250 的 banner，存成 a11.jpg；所有素材都要用到，文字必須清楚可讀。

成品

製作方式

  1. 建立 300×250 的畫布，上方 120px 切成三等分，三張鞋款照片各自等比例裁切後填滿，確保三個素材全部用到。
  2. 照片下緣加一條深色分隔線，讓圖片區與文案區界線清楚。
  3. 依 text.txt 的文案排版：WEEKEND / SPECIAL SALE / save up to / 30% / SHOP NOW。
  4. 主標用粗體、紅黑對比色，並保留足夠留白讓文字在小尺寸下仍清楚可讀；右下角放圓角的 SHOP NOW 行動按鈕。

產生成品的完整程式：build.py（Python + Pillow）

使用素材

  • photo1.jpg、photo2.jpg、photo3.jpg：三張鞋款照片
  • text.txt：banner 文案
