A02: Vectored artwork

依 icons_sample.jpg 重新繪製 12 個圖示，且必須是向量圖。

成品

製作方式

  1. 分析參考圖：4 列圖示（信封、滑鼠游標、地圖定位、地球）× 3 種樣式（線框、實心、圓底反白）。
  2. 取樣參考圖的顏色，得到紫 #9b2fd6、綠 #12c25a、紅 #f20d1a、藍 #1fbdf0。
  3. 用純手寫的 A02.svg 建立向量稿：以 rect / polyline / path / circle / ellipse 描述每個圖示，並用 <defs> + <use> 重複利用形狀。
  4. 為了同時交付點陣檔，另以 Pillow 依相同幾何（貝茲曲線取樣成折線）4 倍超取樣繪製後縮圖輸出 A02.jpg。

產生成品的完整程式：build.py（Python + Pillow）
