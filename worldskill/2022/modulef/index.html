Top 4 features

Everything a web game needs, built in

Pick a feature to preview it. The four panels below are switched with pure HTML and CSS, so they keep working when JavaScript is turned off.

Every version stays playable

Each upload becomes a new version with its own URL. Players can jump back to the build they love, and developers can ship an update without losing a single score.

A leaderboard worth competing for

Scores are verified on the server and published instantly. One global board per game keeps players coming back — and keeps sessions long enough to matter.

A profile built to show off

Every player gets a public page collecting their best runs, badges and world ranks — one link they can share anywhere.

Ranking that surfaces the good stuff

Weekly rankings mix plays, retention and ratings, so a great game from a small studio can reach the front page on its first weekend.
