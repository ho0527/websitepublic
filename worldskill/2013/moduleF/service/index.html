WSC Statistics – central web service

This folder simulates the central server described in Module F (vhost32.skill17.local/Module_F/). The Module F front-end reads its data from here over SOAP at request time, so any change made to the XML files below is immediately visible in the front-end.

SOAP endpoint

  • WSC_Statistics.php?wsdl – service description
  • getList('countrys'), getList('skills'), getResults()

Plain XML (data source of the SOAP body)

  • data/WSC-Countrys.xml
  • data/WSC-Skills.xml
  • data/WSC-Results.xml

Sample subsets for trade 01 and 02

  • data/WSC-Countrys_trade01_02.xml
  • data/WSC-Skills_trade01_02.xml
  • data/WSC-Results_trade01_02.xml
